# AgentXR

[English](README.md) | 简体中文

面向动手操作的相机助手。AgentXR 使用 Codex 理解操作现场、跟踪任务进度，并通过画面标注提示下一步。

## 核心功能

- **视觉指导**：拍照分析或持续采样相机画面，流式显示操作指引、目标框和箭头。
- **任务上下文**：记录目标、步骤、反馈与观察结果，并在本地保存会话。
- **面包板支持**：标定孔格、复核端点候选，再用确定性电路规则检查已确认的连接。

## 快速开始

需要 Python 3.10+、已登录的 Codex CLI，以及支持摄像头的 Safari 或 Chrome 等浏览器。基础观察功能仅使用 Python 标准库，无需安装 npm 依赖。

```sh
git clone git@github.com:SoniaSuns/AgentXR.git
cd AgentXR
python3 server.py
```

打开 [localhost:8765](http://localhost:8765)，开启摄像头，输入任务，然后点击 **拍照并分析** 或 **开始流式观察**。macOS 也可双击 `start.command` 启动。

流式观察会在每轮分析完成后，等待所选间隔再采下一张。点击 **切换单次拍照** 可停止自动采样并拍一张新照片；若已有分析在运行，新照片会等待它结束后处理。

每张照片只发起一次完整分析，结合用户反馈与选定的历史照片。补充细节请求只记录信息，不再替换诊断或隐藏诊断面板。已移除自动裁剪、重试读取、再回到完整诊断的多轮分析链；仍可手动选择局部细节。

指导优先简短说明“把什么从哪里移到哪里”。照片中的相对位置明确时，无需先填写完整接线计划；移动对象和目标位置会保留标注，并补上两者之间的箭头。详细判断与动作效果记录默认折叠。点击“放大查看操作图”或“放大操作图”，可用 ＋/−、滚轮或双指缩放，拖动查看，双击或“适应窗口”复位；照片和标注同步缩放。

网络默认使用 `settings.json` 中的 `"proxy": "auto"`。每次新分析前依次检查 macOS 已启用的系统代理、0dcloud 配置的本地代理端口、代理环境变量；不可连接的端口会跳过，均不可用时使用系统网络（包含 Surfshark VPN 或 TUN 路由）。检测只确认代理端口可连接，不保证模型服务可用，也不负责开启或切换 VPN 节点。路由变化在下一轮分析生效，页面会显示实际选用通道。

可将 `proxy` 设为明确的代理 URL 来固定通道（失败时不自动改为直连），或设为空字符串固定使用系统网络；`AGENTXR_PROXY` 环境变量或 `--proxy` 参数可覆盖配置。`codex.transport` 默认请求 HTTP/SSE，但当前 CLI 的内置提供方仍可能使用 WebSocket；实际协议必须以 CLI 连接日志为准，健康接口的 `model_transport_requested` 仅表示配置意图。设置为 `"auto"` 可保留 Codex 默认传输选择。修改后需重启后端；之后切换可检测的代理通道无需重启。

## 可选：面包板工具

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-vision.txt
.venv/bin/python server.py
```

冻结清晰画面、完成板面标定并确认端点后，再检查连接。模型候选需要人工复核，目前不支持无人监督的照片转网表。标定与测量方法见[面包板使用指南](docs/BREADBOARD.md)。

## 范围与数据

历史分析记录及其照片默认保留至手动删除（`memory.saved_records: 0` 表示不按条数自动清理）。在历史记录中点击“作为历史参考”，下一轮分析就会附带该照片，不限制拍摄时间；每次只指定一张，照片会明确标为历史证据。点击“取消历史参考”或切换会话即可取消。此前已删除的照片无法恢复。

AgentXR 是使用二维标注的本地研究原型，只分析选中的照片，不逐帧处理视频。照片会发送至 Codex 使用的模型服务；默认在本地保存会话及图片。电路检查依赖板型配置与已确认的输入，仍需实物验证。
